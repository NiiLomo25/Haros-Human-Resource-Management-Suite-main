KNOWN TEST-HARNESS LIMITATION (not a product defect)
  Running `--arch both` in a single invocation proved flaky in this
  environment: each step spawns elevated NSIS processes via UAC consent,
  and NSIS delegates real work to async temp-copy workers (Un_A.exe).
  When UAC prompts are not promptly approved (or AV/disk slows the
  workers), later steps can stall and cascade. Per-arch runs
  (`--arch x64`, `--arch x86`) passed cleanly and repeatably, and a
  manual uninstaller run removed a full install in <10 s. Recommendation:
  run the suite per-arch, or run `--arch both` while actively approving
  UAC prompts.

OFFLINE INSTALLATION — manual verification procedure:
  1. Disconnect the test machine from all networks (Wi-Fi/Ethernet).
  2. Run HRMIS-Setup-x64.exe (or HRMIS-Setup-x86.exe); complete install.
  3. Launch "Haros HRMIS"; verify the app opens and creates
     %LOCALAPPDATA%\HRMIS\Database\hrmis.db.
  4. Reconnect the network.
  The installer is a single self-contained NSIS executable with no
  download stage, so offline installation is expected to succeed; this
  procedure confirms it on target/disconnected hardware.
