PROJECT MASTER PROMPT
HUMAN RESOURCE MANAGEMENT INFORMATION SYSTEM (HRMIS)
1. PROJECT OVERVIEW
Act as a Senior Software Architect, Enterprise Application Developer, Database Engineer and UI/UX Designer.
Your task is to design and develop a comprehensive Human Resource Management Information System (HRMIS) as a fully functional Windows Desktop Application.
The application will be used by Human Resource Departments to manage staff information, departmental structures, staff movements, promotions, transfers, employee records and all other essential human resource management functions.
The application must be suitable for government institutions, Ministries, Departments and Agencies (MDAs).
The system must provide a centralized employee database that maintains the complete employment history of every staff member from recruitment to retirement or separation.
The application must be professional, secure, scalable, reliable and easy to operate.
The application must work completely offline without requiring an internet connection.
PROJECT NAME:
Haros Human Resource Management Information Suite

4. Important Technical Considerations
There is one issue I want you to consider carefully.
You requested both 32-bit and 64-bit compatibility.
I recommend producing two separate installers rather than trying to create one installer for both architectures.
Requirement	x86	x64
Windows 32-bit	Yes	No
Windows 64-bit	Yes, where supported	Yes
Installer	HRMIS-Setup-x86.exe	HRMIS-Setup-x64.exe
Database	SQLite	SQLite
Offline operation	Yes	Yes
Also, keep the employee database outside the application installation folder.
For example:
C:\ProgramData\HRMIS\Data\
This prevents application upgrades from accidentally destroying employee records.
For an offline environment, I recommend SQLite for a single-computer installation. If several HR officers will access the same database simultaneously from different computers, you should consider a separate centralized database architecture.
